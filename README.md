\----------------------------------2026.07.30

이제 카드와 entity는 modifier라는 것을 list<>로 가지고 있습니다.

modifier는 버프와 디버프의 역할을 수행할 예정입니다. 

실제로 카드의 공격력과 파워를 Get()하기 위해서는, 해당 카드의 주인과 카드 본인이 가진 modifier를 foreach()문을 돌면서

합산하여 return합니다. 그러므로 modifier를 적절히 배치하면 버프와 디버프로 활약할수 있습니다.

또한, modifier가 변경될때마다 이벤트버스를 터트려서 카드의 UI도 변경하도록 일단 만들었습니다.(왼쪽에 크게 보이는 카드는 아직 변경 X)

modifier는 trigger중 하나를 가질수 있고 해당 trigger가 실제로 일어나면 스택을 1감소시키고 스택이 0이되면 소멸합니다.

지금은 테스트로 cardusemanager스크립트에 카드를 넣는 코드외에 modifier도 시작하자마자 플레이어한테 부여하고 있는 것을 볼 수 있습니다.

그러나 나중에 가면 카드의 효과에 modifier를 넣는 식으로 할 예정으로 운영할것입니다.
