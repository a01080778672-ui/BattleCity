\------------------2026.06.19
종강하고 허무하게 할게 없어서 작업을 조금더 진행했습니다.
이제 이벤트 버스에 카드 relocate가 있을텐데 이걸로 카드의 위치를 옮길수 있습니다.
카드의 위치는 Common클래스에 Zone에 대한 enum열거형이 있어 이걸 씁니다. (손패존 무덤존 등등...)



시작 준비state>플레이어메인턴(공격시 이너미 방어시도턴을 다녀옵니다)>플레이어 방어 세팅턴>이너미 메인턴(공격시 플레이어 방어시도턴을 다녀옵니다)>플레이어 메인턴...을 반복하도록 만들었으며
이제 FSM매니저에서 상태가 어떤거에서 어떤걸로 바뀌었다고 이벤트를 터트리므로 더 용이하게 쓰실수 있으실겁니다.
예시로 이너미 턴에서 플레이어 턴이 됐을때만 카드를 뽑아오게 하고싶다면 위의 이벤트를 이용합니다.

그 외 주의할점이 있습니다. 카드 DATA를 관리하는 GameLoopData의 카드 List함수들은 함부로 건들면 안됩니다. UI동기화 만들면서 그렇게 만들어졌습니다.



플레이어 메인 페이즈땐 공격카드를 사용하면 공격시도를 하고 방어카드를 쓰면 무조껀 방어존에 보내려 시도합니다.
플레이어 방어 세팅 페이즈땐 공격카드나 방어카드 모두 방어존에 보내려 시도합니다.
플레이어 방어 시도 페이즈땐 세팅됐던 방어존의 카드들로 방어시도를 할수 있게 합니다.





현재 구현이 안된것들: 페이즈가 넘어갈때 플레이어가 선택했던 카드를 취소시켜야함. 이때, UI상에서도 선택됐다는 것을 취소시켜야 하므로 쉽지만은 않을것 입니다.
방어 시도때 방어카드를 선택했다는 표시가 재대로 안 됐습니다. 이 역시 만들어야할 것 입니다.





\------------------2026.06.23

이번에는 아트분들이 해주신 것을 기반으로 대입하는 작업을 진행하였습니다.

카드 뒤집기 기능이 추가되어 카드를 뒤집을 수 있습니다.

해상도는 일단 1600x900 고정입니다.

이제 FSM 상태기반을 오른 위에 따로 표시합니다. 플레이어 메인 페이즈인지 뭔지 글자로 표시해준다는 의미입니다.



카드가 필드에 나갈때 작아지는데 이게 조금 부자연스럽습니다. 아마 에셋을 세분화하고 작아지게 해야할 것 같습니다.

지금 막 고치면 좋은건, 카드의 크기 조작부분인 것 같습니다.
